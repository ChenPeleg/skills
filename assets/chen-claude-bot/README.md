# chen-claude-bot logo

The avatar of the `chen-claude-bot` GitHub App, which opens the PRs that Claude Code sessions push to `claude/**` branches (see the [claude-bot-prs](../../skills/claude-bot-prs/SKILL.md) skill).

| File | What it is |
| --- | --- |
| [`logo.png`](logo.png) | 1024×1024 PNG, the file uploaded to the App (App settings → General → Display information → Upload a logo) |
| [`logo.svg`](logo.svg) | Source, 512×512 viewBox |

A friendly bot head in Claude-like colours (terracotta `#D97757`, cream `#F5F0E8`, near-black `#1F1E1D`), with human eyes and ears and a spark on its antenna. The spark is a generic starburst, not Claude's logo.
